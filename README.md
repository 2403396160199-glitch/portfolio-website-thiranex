# Accessible Portfolio Website

This is a fully accessible multi-page portfolio website built using:

- HTML5 Semantic Tags
- CSS3
- JavaScript
- WCAG Accessibility Guidelines
- SEO Best Practices

## Features

- Semantic HTML structure
- ARIA labels and accessibility support
- Responsive design
- SEO optimized meta tags
- Keyboard accessible navigation
- Accessible contact form

## Pages

- Home
- About
- Projects
- Contact
